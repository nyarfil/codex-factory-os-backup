# 面形状をできる限り保ったソリッド化

## 診断と段階処理

- メッシュを閉じた立体の境界として解釈する。STLなら重複面、縮退三角形、境界辺、非多様体辺、向き、自己交差、連結成分を確認。近接頂点を統合する距離は単位と必要精度に合わせ、測定なしに全体へ大きなweld/decimate/smoothをかけない。
- 三角面STEPなら `BRepCheck_Analyzer`、shellの閉鎖、`BRepAlgoAPI_Check` を別々に確認。`isSolid` / `IsClosed` / BRepCheckが真でも自己交差ゼロとは限らない。
- 体積ゼロの形状をすべて自動削除しない。意図したサーフェス・基準面と、不要な薄片を区別して今回の指示の範囲で清掃する。

## 欠けた境界を埋める

1. 自由辺を同じ部品内でグラフ化。各境界頂点の次数2・閉ループを検証。枝分かれや開いた鎖は未解決として扱う。
2. 穴が設計上の開口か欠損かを画像/隣接面/断面で判定。ネジ穴やUSB開口を「穴だから」とふさがない。ZA13内部固定部品では入口を残して欠けた内壁を追加した。
3. 平面に近い小欠損は既存境界点を使って三角分割する。凹多角形では単純な扇状分割を避け、単純投影と内部対角線を検証する。折れた境界は短い継ぎ目で分割する方法が使えるが、距離閾値はケース固有。
4. Sewing → MakeSolid → 向き補正 → 幾何検査。自由辺/多重辺/予期しない面削除/部品分裂を記録する。

## 許容差だけで接続した面を修復

ZA13では0.006 mmで接続しただけの候補が、閉じて有効でも自己交差検査で不合格だった。共有頂点が元の面平面からずれていたため、実際の共有境界頂点を通る平面三角形を作り直し、1e-7 mmで再縫合して解消した。

保存ソース `official_solid_exact_boundary_trial.py::rebuild` を参照。これは**平面ファセットで、外周ワイヤだけで記述できる面**用のケース実装。曲面や内周穴を持つ面へそのまま適用しない。近接重複点整理1e-9 mm、縫合1e-7 mmはZA13の実績値で、一般の単位/精度に対する万能設定ではない。

## 本当に交差する面片

`official_solid_regularize.py` は `BOPAlgo_MakerVolume` で交差を分割し、各体積セル内の点をSolidClassifierで確認、元の向き付き三角形に対するwinding numberから材料側だけ保持する。重心が部品外にある場合があるため、重心を無条件に内部点としない。windingが整数近傍にならない、参照の向きが不整合、内部点を認定できない場合は採用しない。

共有内面を取り除いてセルを統合する場合は同一面の使用数と向きを検証し、部品数・穴・材料領域を再確認。ZA13側面とUSBは分割後にもう一度共有境界再構築とセル判定が必要だった。大きな部品を無制限に同じ演算へ再投入せず、異常位置とチェックポイントから次の最小修復を決める。

最後に全ての異常ステータスを評価する。保存された旧スクリプトの中にはSelfIntersectだけを数えるものやCheckのコンストラクタ後にPerformを重複実行するものがある。新規実装では空コンストラクタ→SetData→Performを一回とし、最終合格判定は `scripts/audit_step.py` の全ステータス検査で行う。
