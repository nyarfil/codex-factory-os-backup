# Software Factoryからの利用

既存リポジトリの規約・構造を先に確認する。新規UI/Tauri/DSPの構造設計、または既にHDVSを採用したプロジェクトの関連変更でだけ [HDVS](../capabilities/architecture-hdvs/GUIDE.md) を読む。既存の別方式へHDVSを強制しない。通常の調査・小修正では全編を読まない。

GitHubは `github@openai-curated-remote` 一系統を使う。旧GitHub MCPは戻さない。Serenaは[プロジェクト確認手順](serena.md)に従い、現在のプロジェクトを自動検出・確認して使う。JCK固定設定はない。
