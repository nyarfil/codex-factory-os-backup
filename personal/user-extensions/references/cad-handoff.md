# CAD専門機能の引継ぎ

factory-cad-3dpを担当として維持し、CADの作成・変更・評価ではこの引継ぎ条件を使う。既存の正本を優先し、Text-to-CAD、Fusion、ForgeCADの派生物を別々に修正しない。新規案件の方式は指定・要件・利用可能な環境から担当Factoryが決め、旧スキルのText-to-CAD固定宣言は復活させない。

- 市販部品を組み込む場合は、step-parts等で実物のCADを探してから必要に応じて近似を作る。近似を実物寸法の証拠として扱わない。
- 複数部品、PCBと筐体、可動部、ねじ、重要な隙間、複雑な形状ではFusionの独立検証に価値があるかを検討し、利用可能で有効なら自発的に使う。単純部品へ全ツール使用を強制しない。
- [検証条件](cad-verification.md)を使い、適用項目・閾値・実測値・手法・対象ファイルを記録する。組立姿勢だけでなく挿入経路、組立順序、工具アクセスも対象にする。
- 独立検証では正本由来の同一ファイル、ハッシュ、単位、座標、閾値を揃える。不一致を平均で隠さず調査する。
- 保存した最新形状の画像を実際に確認する。criticalな確認ができない場合は未検証と記し、完成品とは呼ばない。寸法の一致は強度・寿命・実機保持性能の証明ではない。
- 評価依頼は読み取り中心。スキルの選択だけで元文書の変更・クラウド保存・印刷開始まで許可されたとは扱わない。
