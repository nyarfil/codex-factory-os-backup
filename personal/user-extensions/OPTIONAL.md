# 必要時に読む追加能力

Factory OSの担当Factoryが選択した機能だけを読む。下記は資料の復元であり、外部アカウントの再接続やランタイム起動を意味しない。

| 能力 | 呼び出す場面 | 参照 |
|---|---|---|
| ai-cad | AI-CAD指定・既存CadQuery系案件 | [資料](optional/ai-cad/GUIDE.md) |
| agentcad | Stella_Agentcad指定・既存案件 | [資料](optional/agentcad/GUIDE.md) |
| openscad-design | OpenSCAD指定・既存.scad編集 | [資料](optional/openscad-design/GUIDE.md) |
| forgecad-project-sync | ForgeCADの同期・共有が必要 | [資料](optional/forgecad-project-sync/GUIDE.md) |
| forgecad-image-prompt | CADから画像生成用プロンプトを作る | [資料](optional/forgecad-image-prompt/GUIDE.md) |
| nvidia | GPU・CUDA・Omniverse・物理AI | [資料](optional/nvidia/INDEX.md) |
| hugging-face | モデル・データセット・学習・評価 | [資料](optional/hugging-face/INDEX.md) |
| data-analytics | Factory Dataで高度な分析手法・レポート部品が必要 | [資料](optional/data-analytics/INDEX.md) |

AI-CADとAgentCADの旧パスは環境を探す手がかりであり、現在の作業先を固定する設定ではない。外部への公開・共有・学習ジョブ等は依頼の範囲でのみ実行する。
