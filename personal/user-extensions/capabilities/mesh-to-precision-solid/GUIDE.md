# 精密メッシュ修復・曲面再構築

`factory-cad-3dp` の下で使う専門手順。正本は既存データと今回の指示から担当Factoryが決め、Fusion履歴・既存ForgeCADモデル・Python正本を相互に勝手に置き換えない。インストール済みnative `cad` / `cad-viewer` を生成・検証・表示に使う。環境は [references/runtime.md](references/runtime.md)。

## 方針を選ぶ

| 要望 | 方法 | 利点 | 制約 |
|---|---|---|---|
| 元の細部を残して立体化 | 境界を正確に修復して閉じたBRepへ | 局所変更で済む | 三角面が多いままなので編集負荷は残る |
| ほぼ同じ形で編集を軽くする | 広い面をBスプラインへ再構築し細部を保持 | 面数・読み込み負荷を減らせる | 近似なので許容差と形状比較が必要 |
| ロゴを滑らかに消す | 周囲の支持曲面を延長して局所形状を置換 | 自然な曲率を維持できる | 意図した形状変更として別に検査する |

用途・単位・基準座標・許容差・保持すべき穴/接合部を入力から確定する。未指定の許容差をZA13例の0.03 mmで承認済みにしない。軽量化に先立ち代表部品一つで可否と性能を測る。寸法・外接箱が一致するだけでは表面一致の証拠にならない。

## 実行

1. 入力をSHA-256で固定し、部品名・solids/shells/meshes/faces・向き・体積・境界・自己交差を診断する。元データと未保存Fusion文書を保護。STLは単位情報を持たないため既知寸法と照合する。
2. 立体化は [references/precision-repair.md](references/precision-repair.md)、軽量化は [references/surface-rebuild.md](references/surface-rebuild.md) を読む。自己交差・欠損のある参照を、そのまま軽量化の正解としない。
3. 一部品/一領域ずつ生成してチェックポイントを保存する。各段階で入力/出力ハッシュ、設定、実測値、例外を記録する。許容誤差を増やして閉じただけの状態を完成にしない。
4. [references/validation.md](references/validation.md) に従い、保存STEPを独立に再読み込みし幾何検査、双方向表面差、重要箇所、画像、必要なFusion操作を検査する。失敗した検査に対応する正本だけ修正する。
5. 合格した部品だけ完成品フォルダへコピーしてハッシュ照合。試作・レポート・キャッシュを混ぜない。ZA13では `V:/mouse/ZA13/ZA13-Official/` が完成品フォルダ。既存完成品の上書きは今回の指示に従う。

## 再現資料

[references/za13-case.md](references/za13-case.md) に実績、段階別スクリプト、失敗条件を記録。`references/za13-sources/` は成功手順に必要な当時のPythonソースの保存版で、ZA13固有パス・部品番号がある。直接一括実行しない。

`scripts/prepare_za13_replay.py --mode upper-no-logo --dest <新規の絶対パス>` はハッシュ固定の入力とソースを検証し、出力先を書き換えた隔離用コピーを作る。生成コマンドを返すが自動実行しない。`upper-lightweight` と `precision-assembly` も対応。これは検証済み入力/修復チェックポイントからの再生成であり、未知のメッシュを無条件に自動修復する道具ではない。

`scripts/audit_step.py <STEPまたはBREP> --out <新規JSON> --expected-solids N` は保存形状の幾何・閉鎖・正体積・自己交差を検査する。合否は終了コードとJSONで判断する。寸法比較や画像検査の代用にはしない。

新しい対象では分割領域・パラメータ化・修復穴の意味を診断し直し、ケース固有の面数/region ID/座標や部品削除を流用しない。会話で許可されたロゴ削除・ゴミ清掃を他案件の許可として扱わない。
