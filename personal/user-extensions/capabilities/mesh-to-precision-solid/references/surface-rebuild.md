# 形状を保つ曲面再構築

## 分離するもの

広い滑らかな外面/内面だけを少数のパラメトリック曲面へ置換し、穴・開口・縁・ネジ座・接合面・小さな特徴は残す。外面と内面を別々に保持し、厚みも確認する。外面への単純offsetで内側を置き換えない。

ZA13の実装順は diagnose → feature_regions → fit_probe → angular_fit_probe → hybrid_rebuild → export → saved-STEP validation。角度分割のregion IDはそのメッシュだけに有効。元メッシュのハッシュとラベル配列を対で固定する。

## パラメータ化・フィット

1. 面法線と隣接面角度で広い領域を分ける。単純な `z=f(x,y)` は側面が立つ形や同一XYに複数Zがある形で成立しない。
2. 一対一で折り返しのないUVを選び、被覆/向き/ヤコビアン/境界の自己交差を確認する。別形状には複数パッチが必要になり得る。
3. ZA13では `u=degrees(atan2(x,z+5))`, `v=degrees(atan2(y-5,z+5))` の角度座標が有効だった。これらの中心位置はZA13固有。5度以内の隣接面グループから外側4/内側3を選択し、Y>-40 mm、境界2リングを除いた領域を使った。
4. 頂点と三角形重心からXYZを別々に3次のテンソル積Bスプラインへ最小二乗フィット。ZA13はノット間隔3度、二階差分正則化1e-6、対角安定化1e-12。外側2448/内側2444制御点。RMSだけで採用せず、最大値・外れ位置・保存後の双方向距離を検査する。

`official_upper_surface_fit_probe.py` に疎行列basis/fit、`official_upper_hybrid_rebuild.py` にUV/曲面構築と縫合がある。ソルバー有限性だけで形状品質を保証しない。未測定の部分・穴の内部まで外挿するときは局所曲率や断面も確認する。

## 境界と残した細部

- UV外周は反時計回り、穴は時計回り（曲面の向きと併せて確認）。同じ境界edgeを再利用して隣接側も同じ3Dカーブに接続する。
- 元三角形の辺はフィット曲面上では曲線になる。単純な平面三角形だけでは一致しないため、境界に接する小領域を曲線辺付きの補間面で再構築する。
- ZA13は `Geom2d_BezierCurve` の直線UV辺から曲面上edgeを生成、BuildCurve3d、共有cacheを使用。隣接三角形はBRepFill_FillingのC0境界拘束でつないだ。これは継ぎ目全体のG1/G2保証ではない。画像・断面・法線変化で段差/折れを検査し、より高い連続性が必要なら別途設計する。
- 縫合後に閉じたshell1個、有効solid1個、自由辺0、多重辺0を確認。個々の遷移頂点の移動も計測する。

## ロゴを自然に埋める

ロゴの周りが既存Bスプライン面の内周トリムになっている場合、フィットをやり直さず同じ支持曲面の内周だけを外す。保持領域の隣接グラフからロゴ島を特定し、その境界edge集合とトリム穴のedge集合が完全一致することを確認して島/遷移面を除く。平面キャップや全面スムージングは不要。

ZA13では1726面を除き、残した13822面が前版と面ごとのBREPバイト単位で一致した。変更した外面も支持曲面の全制御点/ノットを保持し、内面は面全体で一致した。穴が複数ある他モデルでは、ロゴ以外の穴を消さない。ロゴ削除部分を一般の外形許容差検査から分け、意図した変更として記録する。
