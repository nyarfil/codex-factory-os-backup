# 保存後の検証と採用判定

## 幾何

STEPを独立に再読み込みし、入力とのハッシュ対応、期待部品数、全形状のBRepCheck、閉鎖shell、正の体積を確認。solidに属さない余剰面も残っていないことを確認する。各solidの自己交差/微小辺等を `BRepAlgoAPI_Check` で検査し、全異常一覧を保存。部品内自己交差ゼロは部品間干渉ゼロの証拠ではない。

native `cadgen step inspect refs FILE --facts --planes --positioning` と `cadgen step inspect validate FILE` を実行する。独立SI検査済みの場合のみ後者の `--skip-self-intersection` を使い、省略理由と同じSTEPハッシュに対応した検査結果をリンクする。CLIのオプションはインストール版のhelpで確認する。

## 表面差・重要寸法

両方向で「頂点、面重心、辺中点→相手の面への最近接距離」を測る。点同士の距離や一方向の距離だけでは追加面/欠落を見落とす。曲面の表示用三角分割公差は許容差より十分小さくし、最大/RMS/分位値、閾値超過点、位置、サンプル数を記録。ZA13は0.001 mm deflectionを使用したが、測定最大+deflectionも厳密な連続Hausdorff保証ではない。

外接箱、断面、穴径/位置、取付/接合、最小肉厚を用途に合わせて照合。境界を動かしたならその値を示す。元から欠けた内壁の追加、ゴミ除去、承認されたロゴ削除は局所例外として別々に報告し、外形変形と混同しない。例外領域を拡大して許容差超過を隠さない。

局所修正では面ごとのBREPシリアライズ比較、支持曲面の制御点/ノット、境界の一致を使うと変更していない範囲を強く証明できる。STEP変換後の丸め誤差は別途検証する。

## 画像とFusion

保存STEPの `cadgen step snapshot` を生成し自分で見る。外観と裏側、重要断面、変更部の寄りを選ぶ。`--display rendered` は面の境界線を消した表示、`solid` は境界線付き。断面が空白なら合格扱いせず、実際の保存形状から断面を作る。ビューアのURLは `cadgen viewer --host 127.0.0.1 --json` の返却値から組む。

Fusionはdocument/openとactiveCommandを先に読む。APIのSTEP importToNewDocumentで検証用の新規文書へ読み込む。既存文書を上書き・保存・閉鎖しない。通常のスクリプトがダイアログで拒否されたら、読み取りだけ続け、変更が必要な場合はダイアログを閉じてもらう。`readOnly:true` を変更制限の回避に使わない。

Fusionのcm→mmは10倍、cm³→mm³は1000倍。体積の既定Low精度は±1%、VeryHighは±0.01%なので、OCCTとの体積差を判断する前に計算精度を揃える。isValidはAPI参照の有効性であり幾何証明ではない。preciseBoundingBox、solid数、重要面を照合する。

性能は同じ部品/同じ演算/同じ条件で比較する。読み込み、複製、想定する穴あけ/差分などを一時コピーで測る。面数やMBが減っても全演算が速くなるとは限らない。測定回数と未実測の操作を明記し、Fusionフリーズ時は同じ全体演算を繰り返さず外部で部品ごとに処理する。
