# Codex Factory OS バックアップ

2026-09-20時点のFactory OS 1.1.0と個人拡張、および初期化前資産の非公開バックアップ。

| フォルダー | 内容 |
|---|---|
| factory-os/ | Factory OS標準の配布物。個人拡張と分離 |
| personal/ | 現行の個人拡張、必要時参照47件、Serena/Fusionなどの可搬設定 |
| archive/ | 初期化前のスキル・ルール・プラグイン資料。通常のスキル探索先へ一括復元しない |
| records/ | 棚卸し、採否、検証結果、依存バージョン、元ファイルの記録 |

Factory OSが最上位。個人拡張はuser-capabilitiesを入口に必要な資料だけ読む。SerenaはJCK固定をやめ、現在のプロジェクトを自動検出・確認して使用する。

[復元手順](RESTORE.md)を参照。`python restore.py`はファイルの整合性確認と復元先の表示だけを行う。書込みには`--apply`が必要で、既存カスタマイズがある場所への上書きは拒否する。

認証情報、会話履歴、プロジェクト本体、実行バイナリー、依存キャッシュ、Git内部履歴は含まない。プラグインの認証・外部アカウント接続は復元後に再設定する。これはOS全体やプロジェクト成果物のバックアップではない。

第三者のスキル・ライブラリー資料を含む。各フォルダーのLICENSE等を保持している。公開リポジトリへ変更する前には、内容とライセンスを確認すること。
